## Expertise Risk AI

Hackathon demo for mapping critical organizational expertise, simulating expert departure risk, and converting uncovered knowledge gaps into evidence-based hiring requirements.

### Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

### Demo flow

1. Review company-wide knowledge risk on the dashboard.
2. Search for "Who knows authentication best?"
3. Inspect Sarah Chen's evidence-backed expertise score.
4. Simulate Sarah leaving.
5. Generate the Authentication hiring spec from the detected gap.
